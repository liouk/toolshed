# :hut:	toolshed

The Toolshed is a place to store various little tools and scripts that I use and don't have a home in some other repo.

## Tools

### Go

- **[glone](glone/)** — TUI for browsing, cloning, and opening GitHub repos from your orgs
- **[goot](goot/)** — TUI for adding tasks to Google Tasks + CLI for querying completed tasks

### Shell

- **[opa](opa/)** — 1Password CLI wrapper with fzf and persistent sessions
- **[fzfpac](fzfpac/)** — fzf-powered pacman search
- **[skratch](skratch/)** — Quick scratchpad notes
- **[zed-picker](zed-picker/)** — Zed project picker

### Web

- **[zapping](zapping/)** — Retro-styled HTML page to organize YouTube playlists
